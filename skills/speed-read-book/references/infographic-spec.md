# 全书信息图规范

## 生成时机

先完成并核验文字版报告，再制作信息图。信息图是报告的视觉索引，不能替代章节分析。

## 默认规格

- 比例：2:3 竖版；
- 语言：简体中文；
- 风格：清晰、克制、适合阅读和收藏；
- 字体：高对比、字号层级明确，避免大段小字；
- 输出：优先保存到当前项目的 `outputs/`。

## 必备内容

根据书的实际内容选择布局，但应覆盖：

- 书名、作者；
- 全书核心问题；
- 3 至 7 个核心观点或主题；
- 全书逻辑、时间线或叙事推进；
- 关键概念及关系；
- 关键人物或案例；
- 章节地图；
- 对读者的启发；
- 主要限制或争议；
- 一句话总结。

不要为了填满画面捏造数字、人物、引用或英文名称。信息密度过高时，应减少装饰和次要文字，而不是缩小到不可读。

## 图像提示词

根据已核验报告生成具体提示词，至少写明：

- 书名、作者与内容类型；
- 视觉结构，例如时间线、概念地图、论证阶梯或人物关系；
- 必须出现的中文文案；
- 配色、留白、层级和 2:3 比例；
- 不得新增未经报告确认的事实、引文和数据；
- 中文文字必须清晰可读。

## 不可用时的替代

没有图像生成能力或生成失败时，明确写“本次未生成图片”，并给出：

1. 画布比例与分区；
2. 每个区域的标题和文字；
3. 连线、箭头或时间线关系；
4. 配色与字体建议；
5. 可直接交给设计师或图像模型的完整提示词。

不要提供不存在的图片链接。
