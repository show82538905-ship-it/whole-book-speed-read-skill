# 续写、章节追问与后续问答

## 长报告续写

### 何时分段

当单条回复无法兼顾完整章节与可读性时分段。不要为了强行一次交付而把每章压成一句话。

### 断点格式

在完整章节或完整大节后停止，并写：

```text
本次已完成：……
下一部分将从：……

输入 continue 或者 C 继续。
```

用户输入 `continue`、`C`、`c`、`继续` 或 `接着写`，都视为同一指令。

### 断点状态

可写文件时维护简洁状态，至少记录：

- 书名与所用版本；
- 原始文件路径；
- 完整章节清单；
- 已完成章节；
- 下一章节；
- 已生成报告文件；
- 尚待核验的问题。

状态文件放在当前工作目录的 `work/`，不要混入最终开源包或用户报告。续写前先读取已生成报告和状态，再从下一节开始，避免改写或重复已完成内容。

用户在续写期间补充文件时，先判断它是补充材料、新版本、缺失章节还是另一卷。说明对既有结论的影响后再继续。

## 章节追问

用户问“这一章有什么有趣的事实、故事或金句”时，回到对应章节原文核验，不仅依赖先前摘要。

### 有趣事实或故事

默认选择 2 至 3 项。每项包含：

- 事实或故事的准确转述；
- 它出现在哪一章，能确认页码时附实际文件页码；
- 它为什么重要、有趣或反直觉；
- 它在本章或全书论证中的作用。

### 金句

默认选择 2 至 3 项，并使用：

```text
中文：……
原文：……
位置：第 X 章；文件第 X 页
意义：……
```

只有能从用户文件中逐字核验时才使用引号和“原文”。若文件只有译文、OCR 不可靠或句子无法逐字确认，改写为：

```text
观点转述：……
位置：第 X 章；文件第 X 页
意义：……
核验说明：当前文件无法确认准确原文。
```

保持引文短而必要，不连续摘录长段文字。

## 后续问答

回答人物、概念、论证、情节、现实应用或作者立场时：

1. 先回答书中明确写了什么；
2. 再说明能够从书中合理推断什么；
3. 最后才补充外部知识，并标注“书外补充”；
4. 找不到依据时明确说“在当前已读取材料中未确认”。

若用户的问题涉及法律、医学、投资决策等高风险领域，书中观点只能作为阅读材料，不将其包装成个性化专业建议。
