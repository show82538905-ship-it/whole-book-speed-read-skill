# 全书速读

## 目标

以用户提供的书籍文件为第一事实来源，先确认全书结构与材料完整性，再按真实章节顺序生成可核验的中文速读报告。保留作者论证、叙事推进、关键概念与重要人物之间的关系，不把“压缩字数”当作唯一目标。

## 总体原则

- 优先依据用户文件。只有用户仅提供书名、明确要求补充资料，或文件本身无法确认必要信息时，才使用公开网络来源。
- 把原书内容、作者观点、书中引用或批评的观点、人物观点，以及分析者的推论严格分开。
- 不编造章节、人物、案例、数据、书目信息、原文、页码或英文名称。
- 无法确认原文时写“观点转述”，不要加引号伪装成直接引语。
- 只使用实际文件页码。电子书位置、印刷页码和 PDF 页序不同，要注明采用哪一种。
- 重要人名、机构、理论、产品、地名和书名在首次出现时补充可靠的英文或原文名称；无法确认就保留中文并说明。
- 以摘要、分析和少量必要短引文为主，不输出可替代原书的大段连续原文。
- 发现缺页、重复页、OCR 错误、章节顺序异常或版本不明时，先披露再分析，不默默补全。

## 工作流

### 1. 识别输入与读取方式

先列出所有输入文件、格式、大小和可读状态，并判断它们属于：

- 同一本书的不同格式或版本；
- 正文与补充材料；
- 同一套书的不同卷；
- 完全不同的书。

按文件类型调用当前环境中合适的 PDF、文档、OCR 或文本读取能力。若文件很长，分段提取并保留章节边界，不依赖一次性截断文本。

仅提供书名时，可以检索公开信息，但必须在报告开头写明“本报告未读取用户提供的原书文件”，并在相关段落区分书目资料、可靠书评与分析推断。

### 2. 建立全书清单

在正式写作前建立内部章节清单，至少检查：

- 书名、作者、版本、译者、出版社、出版时间；
- 前言、序言、导言、楔子、正文各章、结语、尾声、后记；
- 具有实质内容的附录、注释或访谈；
- 缺失、重复、乱码、扫描质量和无法读取的范围。

目录不可直接信任。目录、正文标题、页码连续性和文件终点需要相互核对。若材料不完整，明确写出“已覆盖范围”和“未覆盖范围”。

### 3. 选择分析模式

根据原书实际类型选择重点，不机械套模板：

- 非虚构、学术、商业管理、传记历史：追踪核心问题、论点、证据、案例、概念关系、方法、适用边界和反驳空间。
- 小说与文学：追踪人物、欲望、冲突、转折、叙事视角、结构、意象、主题和结局功能；不要强行改写成商业框架。
- 混合类型：分别标注事实叙述、作者解释、文学表达和分析推断。

完整写作顺序和章节模板见 [references/report-spec.md](references/report-spec.md)。开始生成报告前必须读取该文件。

### 4. 逐章提炼并交叉核验

按真实章节顺序处理。每章至少回答：

1. 本章在全书中的功能是什么？
2. 本章推进了什么论点、叙事或人物变化？
3. 使用了哪些关键概念、证据、案例或场景？
4. 它与前后章节有什么因果、对照或递进关系？
5. 哪些内容是明确原文，哪些是分析推断？

遇到重复论述可以压缩，但不得因此漏掉章节。相同概念在不同章节发生含义变化时，要保留变化。

### 5. 生成报告

默认在对话中交付完整结果；环境支持文件写入时，同时把用户可阅读的最终稿保存到当前项目的 `outputs/`，建议命名：

`YYYY-MM-DD--书名短标题__全书速读.md`

报告固定顺序为：

1. 书籍信息
2. 概括全书
3. 全书要点
4. 各章节要点
5. 扩展思考
6. 总体评价
7. 阅读后的核心问题
8. 固定结尾提示

“扩展思考”必须显式标注为外部分析，不能冒充作者原意。“总体评价”要同时说明贡献与局限，避免空泛赞美。

### 6. 控制长度与续写

完整性优先于一次性塞入单条回复。预计无法在当前回复完整交付时：

- 在一个完整章节或完整大节结束后停止；
- 明确说明已完成范围、下一部分起点；
- 提示用户“输入 continue 或者 C 继续。”；
- 用户输入 `continue`、`C`、`c`、`继续` 或 `接着写` 时，从断点继续，不重复前文；
- 可写文件时，把已完成报告和断点状态保存在工作目录中，续写前先读取它们。

续写、章节追问、金句与后续问答的具体规则见 [references/continuation-and-follow-up.md](references/continuation-and-follow-up.md)。进入这些场景前读取该文件。

### 7. 生成信息图

只在文字版报告完成后生成信息图。读取 [references/infographic-spec.md](references/infographic-spec.md)，使用可用的图像生成能力制作默认 2:3 中文信息图。

如果当前环境没有图像生成能力，明确说明未生成图片，并提供可供设计师或图像模型直接使用的版式草图。不得用“已生成”描述不存在的文件。

## 完成检查

交付前逐项确认：

- 已说明文件完整性、版本和实际覆盖范围；
- 章节清单与报告章节一一对应，没有静默漏章；
- 作者观点、他人观点、人物观点、事实、转述和扩展分析已区分；
- 引文、页码、英文名和数据均可回到文件核验；
- 非虚构与文学作品使用了合适的分析方式；
- 总体评价包含证据、适用边界、偏见或过时风险；
- 过长时断点清楚，续写不会重复；
- 信息图只在文字完成后生成；
- 报告以规定的固定提示语结尾。
